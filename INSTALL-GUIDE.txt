ANDROID PAR INSTALL KARNA:
──────────────────────────

STEP 1: Files Upload Karein
  • Ye poori folder apne server, GitHub Pages, ya Netlify par upload karein
  • Ya Google Drive / Dropbox mein daal kar share karein

STEP 2: Chrome Browser Mein Open Karein
  • Android phone mein Chrome browser open karein
  • Website ka URL open karein

STEP 3: Install Karein
  • Chrome ke 3-dot menu (⋮) mein jaayein
  • "Add to Home Screen" ya "Install App" select karein

STEP 4: Ready!
  • Home screen par naya "Chaajao" icon nazar aayega
  • Bilkul app ki tarah kholein — fullscreen chalegi, zoom nahi hogi!

LOCALHOST PAR TEST KARNA:
──────────────────────────

  1. Folder mein jaayein:
     cd chaajao-pwa
  2. Local server chalayein:
     python3 -m http.server 8080
  3. Phone aur PC ek hi WiFi par hon
  4. Phone mein Chrome mein open karein:
     http://[aapka-PC-IP]:8080
  5. Upar wali steps follow karein
